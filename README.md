# Delivery — приложение службы доставки посылок

Нативное Android-приложение на Kotlin для отправки и отслеживания посылок. В роли бэкенда — Supabase: аутентификация и база данных PostgreSQL. Сделано на практике в колледже (2024) в формате поэтапных сессий.

## Возможности

- **Онбординг** при первом запуске
- **Регистрация и вход** по email и паролю, подтверждение почты одноразовым кодом (OTP), восстановление и смена пароля
- **Отправка посылки** — адреса отправителя и получателя, состав и вес посылки, расчёт стоимости (доставка, срочность, сервисный сбор), генерация трек-номера
- **Отслеживание** — информация о посылке и статусе доставки, экран успешной доставки
- **Кошелёк** — баланс и история транзакций, добавление способа оплаты
- **Профиль** — данные пользователя, настройки уведомлений
- **Интерфейс** карты отслеживания, чатов и звонка с курьером — макеты экранов без серверной логики

## Стек

| Часть | Технологии |
|---|---|
| Язык | Kotlin |
| UI | Fragments, View Binding, Navigation Component, ViewPager, Material Components |
| Бэкенд | Supabase — Auth (email + OTP), Postgrest |
| Сеть и данные | Ktor, kotlinx.serialization, kotlinx.datetime, Retrofit, OkHttp |
| Локальное хранение | SharedPreferences |

Минимальная версия Android — 11 (API 30).

## Структура данных

Таблицы в Supabase: `profiles`, `locations`, `packages`, `deliveries`, `transactions`, `routes`. При отправке посылки приложение последовательно создаёт адреса, посылку, доставку, транзакцию и маршрут.

## Что бы я сделал иначе сегодня

- **Не хранить пароль на устройстве.** Функция «Запомнить меня» сохраняет пароль в SharedPreferences; правильнее полагаться на сессию Supabase Auth, которая сама хранит и обновляет токены.
- **Не писать чувствительные данные в лог.**
- **Архитектура MVVM** — сейчас фрагменты обращаются к базе напрямую; ViewModel и репозиторий отделили бы UI от данных и упростили тестирование.
- **Конфигурация вне кода** — адрес и ключ Supabase через `local.properties` и `BuildConfig`.
- **Единый стиль именования** — в коде смешаны `camelCase` и `snake_case`.
